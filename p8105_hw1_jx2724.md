``` r
normal_sample = rnorm(10)

sample_df =
  tibble(
    normal_sample = normal_sample,
    positive = normal_sample > 0,
    character_var = letters[1:10],
    factor_var = factor(
      c(
        "low", "medium", "high", "low", "medium",
        "high", "low", "medium", "high", "low"
      )
    )
  )
```

      {r, warning = FALSE}
    mean(pull(sample_df, normal_sample))

    mean(pull(sample_df, character_var))
    mean(pull(sample_df, factor_var))

The mean can be calculated for the numeric and logical variables, but
not for the character or factor variables. For the logical variable, R
treats TRUE as 1 and FALSE as 0, so the mean represents the proportion
of TRUE values.

``` r
as.numeric(pull(sample_df, positive))
as.numeric(pull(sample_df, character_var))
as.numeric(pull(sample_df, factor_var))
```
